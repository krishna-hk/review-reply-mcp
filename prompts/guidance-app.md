Examples: "crashes when I open settings" is Bugs and crashes negative; "so easy to set up" is Setup and onboarding positive; "wish it had dark mode" is Missing features negative.

- Crashes, error messages and things that plainly do not work as intended are **Bugs and crashes** negative. Lost, missing or wrongly synced data is **Reliability and data safety** negative; add Bugs and crashes only if a crash or error message is described.
- Slow loading, lag, freezing, battery drain or heavy storage use is **Speed and performance** negative. A fast app is Speed and performance positive.
- Not being able to sign up, log in, reset a password, or move data in from another tool is **Setup and onboarding** negative. Add Bugs and crashes only if an error or crash is described.
- Confusing screens, hard-to-find options or a steep learning curve are **Ease of use** negative. "Simple", "intuitive", "easy" are Ease of use positive. How the app looks (colours, dark mode, layout, icons) is **Design and look**.
- Wishing for a feature that does not exist, or saying a feature is missing, is **Missing features** negative. "It has everything I need" is Missing features positive. Praise for a feature that exists goes under the theme it is about (usually Ease of use).
- A new version that broke, removed or changed something people relied on is **Updates and changes** negative, plus the theme of the thing that broke. "Used to be great, now worse" is Updates and changes negative. Praise for an update that improved things is Updates and changes positive.
- Price complaints, paywalls, subscription changes and "not worth the money" are **Price and billing** negative. "Worth every penny" is positive. Being charged twice, charged after cancelling, or a refused refund is also Price and billing negative. Escalate as `fraud` only if the customer calls it a scam, deliberate or unauthorised.
- Slow, unhelpful or missing replies from the support team are **Customer support** negative; fast, helpful support is positive. A bug report alone is not Customer support.
- Permissions, tracking, data collection and account security worries are **Privacy and security** negative. Someone else's data being visible or an account being taken over is also serious: escalate as `other_serious`.
- Comparing with a competitor: tag the theme being compared, and ignore the competitor's name.
- A review about a different product, or a developer or advertiser promoting something, is spam.
